Installer lspf sur votre téléphone

lspf est une Progressive Web App : une fois installée, elle s'ouvre en plein écran comme une application, fonctionne hors connexion et apparaît dans le menu Partager d'Android.

1. Sur le téléphone (Chrome Android)

  1. Ouvrez cette page dans Chrome (l'adresse doit être en https:// ou http://localhost).
  2. Touchez le menu ⋮ en haut à droite.
  3. Choisissez Installer l'application (ou Ajouter à l'écran d'accueil → Installer).
  4. Confirmez : l'icône lspf apparaît sur l'écran d'accueil et dans la liste des applications.

Samsung Internet : menu ☰ → Ajouter la page à → Écran d'accueil. Edge : menu ⋯ → Ajouter au téléphone.

2. Servir lspf en local depuis un PC

Il faut Node.js 20+ sur le PC, le débogage USB activé sur le téléphone et adb (Android Platform Tools).

cd node-lspf-pwa
node build.js                    # construit www/
node serve.js                    # http://localhost:8080
adb reverse tcp:8080 tcp:8080    # le téléphone voit le port 8080 du PC

Sur le téléphone, ouvrez http://localhost:8080 dans Chrome, puis suivez l'étape 1. Après l'installation, le câble n'est plus nécessaire : lspf fonctionne hors connexion.

Réseau local sans câble ni HTTPS : node serve.js --host 0.0.0.0, puis dans Chrome Android chrome://flags → Insecure origins treated as secure → ajoutez http://ADRESSE-DU-PC:8080 et relancez Chrome.

3. Ouvrir un fichier depuis une autre application

Une fois lspf installée, dans le gestionnaire de fichiers, Gmail, Drive… : Partager → lspf. Le fichier est copié dans ~/partages et s'ouvre directement dans l'éditeur en mode VIEW (F3 revient au menu principal).

Mises à jour et données

Une nouvelle version publiée à la même adresse est prise au lancement suivant. Vos fichiers restent dans le navigateur du téléphone : désinstaller l'application les efface, pensez à la Sauvegarde complète (menu ☰).
